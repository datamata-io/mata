# API Reference

## `datamata.kaca.KACA`

```python
class KACA:
    @classmethod
    def from_pack(
        cls,
        slug: str,
        *,
        runtime: Literal["pytorch", "onnx", "tflite", "auto"] = "auto",
        device: str = "cpu",
        pack_dir: str | None = None,
    ) -> "KACA": ...

    def predict(
        self,
        source: str | Path | np.ndarray | PIL.Image.Image,
        *,
        conf: float = 0.25,
        iou: float = 0.45,
        imgsz: int | None = None,
    ) -> DetectionResult: ...

    def predict_batch(
        self,
        sources: list[str | Path | np.ndarray],
        *,
        batch_size: int = 1,
        conf: float = 0.25,
    ) -> list[DetectionResult]: ...

    def info(self) -> dict: ...
    def __enter__(self) -> "KACA": ...
    def __exit__(self, *args: Any) -> None: ...
```

    model_slug: str

    def to_dict(self) -> dict: ...

## `datamata.schema.Detection`

```python
@dataclass
class Detection:
    label: str
    confidence: float
    bbox: BoundingBox
    track_id: int | None = None
    mask: np.ndarray | None = None      # segmentation only
    keypoints: list[Keypoint] | None = None  # pose only
```
