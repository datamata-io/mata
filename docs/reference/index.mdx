# Reference

This section provides complete API references for all datamata public interfaces.

## Modules

| Module | Description |
|---|---|
| `datamata.kaca` | KACA model family — loading and inference |
| `datamata.mata` | MATA Graph — pipeline construction and execution |
| `datamata.matavision` | MATAVISION runtime — end-to-end pipeline tools |
| `datamata.schema` | Typed result objects and serialization |
| `datamata.cli` | CLI utilities exposed as a Python API |

## Type stubs

All datamata packages ship with `py.typed` marker files and full type stubs. Mypy and Pyright are fully supported.

## Versioning

datamata follows [Semantic Versioning](https://semver.org). Breaking changes are announced in the [migration guide](/docs/v0/migration).
