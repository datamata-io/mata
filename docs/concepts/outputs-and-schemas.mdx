# Outputs and Schemas

Every datamata model returns a structured, typed result object. All result schemas are defined using Python `dataclasses` and are serializable to JSON, MessagePack, and Protobuf.

## Detection output

```python
@dataclass
class Detection:
    label: str
    confidence: float
    bbox: BoundingBox       # x1, y1, x2, y2 in pixel coordinates
    track_id: int | None    # populated when tracking is enabled

@dataclass
class DetectionResult:
    detections: list[Detection]
    frame_id: int
    latency_ms: float
    model_slug: str
```

## Segmentation output

```python
@dataclass
class SegmentationResult:
    masks: list[Mask]       # per-instance binary masks
    detections: list[Detection]
    frame_id: int
```

## Classification output

```python
@dataclass
class ClassificationResult:
    top_k: list[tuple[str, float]]  # (label, confidence) sorted desc
    frame_id: int
```

## Pose output

```python
@dataclass
class PoseResult:
    persons: list[PoseKeypoints]
    frame_id: int
```

## Serialization

```python
import json
result = model.predict("image.jpg")
print(json.dumps(result.to_dict(), indent=2))
```
