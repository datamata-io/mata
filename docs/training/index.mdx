# Training

datamata provides training utilities for fine-tuning KACA and other model families on custom datasets.

## Supported training modes

| Mode | Description |
|---|---|
| **Fine-tune** | Continue training from a pretrained KACA pack |
| **Transfer learning** | Freeze backbone, train head layers only |
| **Full training** | Train from scratch (research use) |

## Quick start: fine-tune KACA

```bash
datamata train kaca-nano \
  --data ./dataset/data.yaml \
  --epochs 50 \
  --imgsz 640
```

## Dataset format

datamata uses the YOLO-style dataset format:

```
dataset/
├── images/
│   ├── train/
│   └── val/
├── labels/
│   ├── train/
│   └── val/
└── data.yaml
```

`data.yaml`:
```yaml
train: images/train
val: images/val
nc: 3
names: [cat, dog, person]
```
