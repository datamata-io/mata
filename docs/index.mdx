# MATA Documentation

**MATA (Model-Agnostic Task Architecture)** lets you write a vision pipeline once and swap any model —
HuggingFace, ONNX, Torchvision — without changing your code.

```python
import mata

result = mata.run("detect", "image.jpg", model="facebook/detr-resnet-50")
for det in result.instances:
    print(f"{det.label_name}: {det.score:.2f} at {det.bbox}")
```
